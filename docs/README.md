# Docs

Project documentation for Team 3.

| File | What it is |
|------|------------|
| `working-agreement.md` | Roles, channels, how decisions and conflicts are handled |
| `schedule.md` | Milestones and due dates, mirrored from the GitHub Milestones |
| `fallback-plan.md` | What the team does if the live sandbox is unavailable, and what that cannot show |
| `decisions/` | Decision records: what was decided, why, and the finding behind it |
| `iam-policy-standards.md` | Security requirements for IAM identity policies managed in this repository |

Test materials belong in `tests/`, and run outputs belong in `evidence/`.
